# Как опубликовать материалы команды на GitHub

## Сначала — важное решение о доступе

1. Этот архив содержит сохранённые материалы всех трёх участников и итоговую презентацию с именами и распределением ролей.
2. До публичной публикации получите согласие сокомандников на размещение общей презентации, ноутбуков, результатов и их имён/ролей.
3. Пока согласия нет, создайте репозиторий **Private**. Не включайте в публичный доступ данные, выгрузки, пароли или внутренние ссылки платформы.

## Что загружать

Загрузите содержимое архива репозитория целиком: `README.md`, `.gitignore`, папки `notebooks/`, `docs/`, `assets/` и `presentation/`.

В этой версии находятся все 28 файловых элементов из исходного RAR. Их содержимое сохранено, имена файлов упорядочены для удобства GitHub. Добавлены README и документы, объясняющие состав и ограничения архива.

**Не добавляйте придуманные SQL-файлы или Airflow DAG как будто это оригинальные материалы буткемпа.** Если исходников нет, так и оставляем. При появлении файлов можно добавить их отдельным коммитом.

## Через браузер GitHub

1. Откройте https://github.com/new.
2. Имя репозитория: `alfa-bank-data-engineering-team8`.
3. Описание: `Dota 2 Data Engineering Bootcamp project — Team Polotence #8, II place`.
4. На первом этапе выберите **Private**. Не добавляйте автоматически README, `.gitignore` или license — они уже есть в архиве.
5. Нажмите **Create repository**.
6. Откройте локально распакованный ZIP, войдите в папку `AlphaBank_DataEngineering_Team8` и загрузите её содержимое через **Add file → Upload files**. Важно загрузить именно содержимое папки, а не ZIP-файл как один файл.
7. Сделайте commit с сообщением `Add preserved Alfa-Bank Data Engineering bootcamp materials`.
8. Проверьте, что README отображается на главной странице, открываются Jupyter Notebook и презентация, а структура папок сохранилась.
9. После согласия команды и проверки содержимого можно изменить Visibility на **Public** в Settings → General → Danger Zone → Change repository visibility.

## Что написать в описании и README

Корневой `README.md` уже подготовлен. В нём явно указано:

- команда «Полотенце», №8, II место среди 11 команд;
- распределение ролей участников по итоговой презентации;
- твоя роль в кейсе №23 — бизнес-аналитическая часть, а не разработка всего ETL-контура;
- общая архитектура командного решения;
- какие ноутбуки и документы сохранены;
- чего нет в архиве и почему ноутбуки не являются полностью воспроизводимым локальным проектом.

Не убирайте ограничения воспроизводимости ради более привлекательного вида репозитория: это важная часть честного описания материалов.

## После публикации

- Добавьте ссылку на репозиторий в резюме Data Engineering Intern.
- Отправьте Матвею Сметанко PDF резюме, ссылку на GitHub и итоговую презентацию PPTX.
- В сообщении обязательно напишите: **команда «Полотенце», №8**.
- Если репозиторий остаётся Private, у получателя не будет доступа без приглашения. Для внешнего рассмотрения нужен согласованный публичный репозиторий либо отдельный доступ.
